What this workbench establishes

This records a software leader reference and operator-observed direction checks. It never sends torque, movement, mode, or motor-zero commands. There is no follower activation button.

Leader-following can be developed separately from camera-guided contact. The current camera-to-wrist candidate still fails its 5 mm positional validation. The cameras here provide visual feedback and tag quality; they do not independently measure link angles or certify calibration. Joint ranges, gripper mapping, starting-pose matching and motion controls still need validation before physical following.

Local connection · Camera frames and joint reads are live but are not synchronized calibration samples. Stop the Python server with Ctrl+C before opening another arm/camera client.

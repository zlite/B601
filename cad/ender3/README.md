# Ender 3 reference geometry

`Ender3.STEP` is the unmodified Creality Ender 3 reference assembly from
[Creality's repository](https://github.com/Creality3DPrinting/Ender-3/blob/88c7758cea9d0d00a54fdb238bedb3b33425f409/Ender-3%20Mechanical/STP/Ender3.STEP),
commit `88c7758cea9d0d00a54fdb238bedb3b33425f409`. The upstream GPL v3 license is
included in `LICENSE`. The inspection script, derived structural references and
inspection results were added for this project in October 2026.

This model does not include the installed custom syringe drive or certify the
printer's current placement. `inspection.json` records the original file hash.
